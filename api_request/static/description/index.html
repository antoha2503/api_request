API Request

Configure HTTP API endpoints in Odoo and review their JSON or XML responses in one place.

Configure endpoints

Add an endpoint URL and an optional API key. Run a connection check and see the current connection status for each configured service.

Review API responses

Inspect formatted JSON or XML responses. Nested JSON objects and arrays are easier to read in the structured table view.

Explore response fields

View the field paths found in JSON and XML responses to understand their structure.

Copy response data

Copy the formatted response from the dashboard for further review or use.

Export tables to Excel

Download the selected JSON response as an Excel workbook (.xlsx). Nested lists and objects are placed on separate worksheets, with parent worksheet and row references to keep related data connected.

Import JSON into Odoo

Choose an Odoo business model, map JSON keys to writable fields, and create records from the selected response. Nested object lists can be selected and imported separately.

How it works

  1. Create an API request with the endpoint URL and optional API key.
  2. Use Test Connect to send a GET request and inspect the response.
  3. Open the response dashboard, select a connected service, and switch between Table and JSON.
  4. Use Import to Odoo to select a JSON source, choose a target model, and map fields before importing.
